Aadvik Pandey

19 y.o self-taught software engineer. My core belief is that obsession is good. If I am not obsessed with an activity, whether a problem or figuring out the world, I feel like an ant walking through an endless desert. So that is what I spend my time doing; right now my major interests are in Generative AI, computation & logic, and anthropology. Here is my story.

On weekdays, I am responsible for building & maintaining agents, MCPs and retrieval systems, and as such, I am doing a lot of thinking, trying to answer questions like how do you make tool selection deterministic?, how do you manage context across long-running agent sessions? and how do you maintain retrieval quality across thousands of artifacts? On weekends, I am trying to write my own bytecode compiler + virtual machine to better learn how fundamental ideas like memory & the CPU work.

Alongside this, I am currently reading Gödel, Escher, Bach by Douglas Hofstadter and lifting heavy weights.

My notable works

  • Varta: an app I built for my own school in 12th. It was an announcements app that I directly pitched to my principal, and spent 8 months designing, building, iterating based on feedback from teachers, students & the principal, and eventually onboarded the school around Oct 2024. Read more about its story here.
  • gdoc.vim : I am a huge fan of the keyboard-driven workflow as well as taking notes. This is a plugin that provides Google Docs integration for my primary editor, Vim (here is my vimrc).
  • kevlar : a cross-platform, batteries-included, zero-dependency static site generator built in pure C. Built because I refused to use an off-the-shelf SSG, and wanted to write my own markdown compiler.
  • swt.h : a fully self-contained single header C library that implements Stroke Width Transform, which is an algorithm to extract "strokes" or text across various languages from a scene.
  • Deimos : a computer vision library, implementing a subset of OpenCV's image manipulation functions completely from scratch in C. I wrote a whole computer vision guide to go along with it as a distillation of all my learnings.
  • For a complete list of all my work, see my GitHub.
